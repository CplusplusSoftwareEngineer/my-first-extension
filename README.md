## Описание
Мой первый плагин для Visual Studio Code, разработанный в рамках лабораторной работы №3. Плагин добавляет команду, которая выводит приветственное уведомление.

## Возможности
- Команда «Hello World» в палитре команд.
- Вывод всплывающего уведомления «Привет из моего первого расширения!».

## Использование
1. Нажмите `Cmd + Shift + P`.
2. Введите `Hello World`.
3. Нажмите `Enter`.# my-first-extension
